# Proposal: Add an optional Arthurian legends layer on top of the core medieval sandbox

## Why

The current product direction already defines the Mittelalter-Mod as a Vanilla+ medieval warfare sandbox with optional thematic layers. Paul's request to bring in King Arthur, the Knights of the Round Table, alternate knightly armor, and tournaments fits that direction well, but only if it is modeled as an explicit add-on layer rather than folded into the base identity of every world.

If the Arthurian material stayed only in chat notes, future contributors could implement it inconsistently: as a mandatory campaign, as disconnected decorative content, or as fantasy creep inside the grounded baseline. This change belongs in the canonical OpenSpec layer because it defines product scope, world-profile behavior, and how a named legendary setting coexists with the rest of the mod.

## What changes

- Define an `Arthurian legends layer` as an optional content module above the core Mittelalter-Mod sandbox
- Define the Arthurian layer as parallel to, but separate from, the broader fantasy layer so worlds can mix:
  - core only
  - core + fantasy
  - core + Arthurian
  - core + Arthurian + mythic/fantasy
- Keep the base mod focused on medieval warfare, soldiers, fortifications, and sandbox play
- Introduce Camelot-flavored content as opt-in:
  - Round Table knights
  - tournament gameplay
  - heraldic/ceremonial armor variants
  - named elite companions and rivals
  - legendary structures and quest hooks
- Define optional Arthurian start roles or scenario paths:
  - Arthur
  - Merlin
  - a young knight seeking entry to the Round Table
- Separate grounded Arthurian courtly content from mythic/fantasy Arthurian content so Excalibur, the Lady of the Lake, and Grail-style arcs do not become mandatory baseline features
- Define a phased roadmap for the Arthurian layer so tournaments and heraldry can arrive earlier than full narrative or magical legend systems

## Impact

- Preserves the core mod identity while making room for a recognizable legendary add-on
- Reduces drift risk across tools by recording that Arthurian content is optional, modular, and layered rather than universal
- Creates a controlled bridge between the grounded medieval profile and the later fantasy profile
- No gameplay implementation lands yet; this is a canonical concept and scope anchor for follow-up feature changes
