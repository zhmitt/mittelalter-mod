# Proposal: Implement Camelot, Round Table knights, and renown

## Why

The Arthurian layer needs a singular long-term destination and a lightweight prestige language connecting tournaments, knights, and later role paths. A compact generated great hall plus named allies/rivals establishes that social-faction hub without a separate RPG engine.

## What changes

- Add a Camelot charter that constructs one validated great-hall complex per world
- Persist Camelot uniqueness and location
- Add named Round Table knight roles with ally, mentor, and rival dispositions on the shared soldier foundation
- Add persistent per-player renown tiers and tournament integration
- Gate access and creative presentation behind Arthurian configuration
- Add tests and runtime evidence

## Impact

This adds world saved data and player prestige state. Camelot is a programmatically constructed V1 landmark, not a full city/worldgen replacement. Later structure iteration can preserve the unique location and renown interfaces.
