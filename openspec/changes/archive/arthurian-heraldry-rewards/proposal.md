# Proposal: Implement Arthurian heraldry and tournament rewards

## Why

Courtly Arthurian identity needs visible affiliation before tournaments and Camelot arrive. A small heraldry set plus stable reward currencies gives later event changes concrete outputs without introducing a superior armor tier.

## What changes

- Add four visible heraldic surcoat variants: lion, stag, raven, and grail
- Keep protection at ordinary iron-equivalent level and differentiate identity through presentation
- Add tournament token and champion laurel prestige rewards
- Gate all content behind the Arthurian-layer configuration
- Add localization, models/textures, recipes where appropriate, and verification

## Impact

These identifiers become shared dependencies for tournament and faction changes. The layer extends the existing item/equipment registry and common config; it does not add a parallel combat system.

`primary workspace`; no branch handoff is planned.
